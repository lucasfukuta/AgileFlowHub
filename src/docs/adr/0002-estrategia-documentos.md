# ADR 0002 — Estratégia documental
- Status: Pendente
- Data: 2026-10-20

## Contexto
O problema central é localizar documentos distribuídos em locais diferentes e com nomes inconsistentes.

## Opções
1. Catálogo de metadados/links.
2. Armazenamento gerenciado pelo AgileFlowHub.
3. Modelo híbrido.
4. Agente local para pastas locais/rede.

## Decisão
Pendente. Não implementar sincronização/movimentação até confirmar origem, permissões, comportamento esperado e recuperação.

## Critérios
Segurança, busca, versionamento, recuperação, auditoria, custo operacional e compatibilidade com infraestrutura existente.
